# セキュリティについて / Security Policy

## 対象のバージョン / Supported versions

最新のリリースだけを対象にしています。古いバージョンで見つかった問題は、最新版で直します。

Only the latest release is supported. Issues found in older versions are fixed in the latest one.

## 脆弱性の報告 / Reporting a vulnerability

セキュリティ上の問題を見つけた場合は、**公開の Issue には書かず**、
このリポジトリの「Security」タブにある **「Report a vulnerability」** から非公開で報告してください。
報告の内容は、修正が公開されるまで外部には公開しません。

If you find a security issue, **please do not open a public issue**.
Use **"Report a vulnerability"** in the Security tab of this repository to report it privately.
The report stays private until a fix is released.
