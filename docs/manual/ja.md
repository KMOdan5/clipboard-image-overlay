# clipboard-image-overlay マニュアル

コピーした画像をホットキー 1 つで OBS の配信画面に表示するプラグインの使い方です。

## 1. インストール方法

1. [リリース](https://github.com/KMOdan5/clipboard-image-overlay/releases) から `clipboard-image-overlay-(版)-windows-x64.zip` をダウンロードし、展開します。
2. OBS を終了します。
3. `Win + R` を押して「ファイル名を指定して実行」を開き、`%ProgramData%\obs-studio` と入力して Enter を押します。
4. 開いたフォルダに「plugins」フォルダがなければ作成します。
5. 展開したフォルダの中にある「clipboard-image-overlay」フォルダを「plugins」フォルダの中に置きます。
   置いたあとは `plugins\clipboard-image-overlay\bin\64bit\clipboard-image-overlay.dll` という構成になります。
6. OBS を起動し、「ツール」メニューに「Clipboard Image」があればインストール完了です。

**更新するとき**: OBS を終了し、新しい「clipboard-image-overlay」フォルダで上書きします。設定はそのまま引き継がれます。

**アンインストールするとき**: OBS を終了し、手順 3 と同じ方法で開いたフォルダの「plugins」にある「clipboard-image-overlay」フォルダを削除します。

## 2. はじめての使い方

1. OBS の「設定」→「ホットキー」で、「クリップボードの画像を表示」にキーを割り当てます(おすすめは下記)。
2. 表示したい画像をコピーします。
   - ブラウザ: 画像を右クリック →「画像をコピー」
   - スクリーンショット: `Win + Shift + S` で範囲を選択
   - ペイントツール: 範囲を選択して `Ctrl + C`(透明な部分も透過されます)
   - 画像ファイル: エクスプローラーでファイルを選択して `Ctrl + C`(GIF ファイルはアニメーションも再生されます)
3. OBS で割り当てたキーを押します。

初めて表示したときは現在のシーンに「Clipboard Image」という画像ソースが追加され、画面中央に画像が表示されます。以降は同じソースで画像を切り替えます。

ホットキーの代わりに、「ツール」→「Clipboard Image」→「画像を表示」からも表示できます。

### おすすめのホットキー

迷ったときは次の組み合わせがおすすめです。

| 操作 | ホットキーの項目名 | おすすめのキー |
|---|---|---|
| 画像を表示する | クリップボードの画像を表示 | `Ctrl + Shift + V` |
| 一時停止/再開する | 自動で非表示にするタイマーを一時停止/再開 | `Ctrl + Alt + P` |

`Ctrl + C` でコピーしたら、そのまま `Shift` を足して `V` を押すと片手のまま画像を表示できます。

- 「設定」→「ホットキー」上部の検索欄にキーを入力すると、同じキーが他の操作に割り当てられていないか確認できます。
- Stream Deck などのボタンに割り当てる場合、普段使わない `F13`〜`F24` などのキーもおすすめです。

## 3. 画像の表示と非表示

- 画像はフェードインし、表示時間(既定 10 秒)が経過するとフェードアウトして非表示になります。
- 表示中にもう一度ホットキーを押すと、今の画像がフェードアウトし、新しい画像がフェードインします。表示時間は最初から数え直します。
- 非表示にする場合、すべてのシーンの「Clipboard Image」が対象です。表示中にシーンを切り替えても元のシーンに画像が残りません。

## 4. 一時停止と手動で非表示にする方法

- 「自動で非表示にするタイマーを一時停止/再開」のホットキーを押すとカウントが止まり、画像は表示されたままになります。もう一度押すと残り時間から再開します。
- 一時停止中に新しい画像を表示した場合は一時停止のまま画像が切り替わります。
- 手動で非表示にするときは、ソース一覧の目のアイコンか、「設定」→「ホットキー」の「'Clipboard Image' を非表示」を使います。このホットキーはシーンごとに並んでいるので、使うシーンそれぞれで割り当ててください。
- 画像が非表示になると一時停止は解除されます。
- 目のアイコンなどで手動で表示した場合も、ホットキーで表示したときと同じく表示時間が経過すると非表示になります。

## 5. 設定

「ツール」→「Clipboard Image」→「設定...」で開きます。

| 項目 | 既定値 | 内容 |
|---|---|---|
| 表示時間 | 10 秒 | 0〜999 秒。0 秒にすると画像は手動でのみ非表示になります。 |
| 最大サイズ | 60% | 10〜100%。キャンバスに対する割合です。設定値を超える画像は自動縮小します。 |
| 常に最前面に表示する | オン | 画像を表示するたびに「Clipboard Image」を最前面へ移動します。オフにするとソースの表示順序を維持します。 |

- 「適用」を押すと設定画面を開いたまま保存します。画像を表示しながら調整できます。
- 設定内容は次に画像を表示したタイミングで適用されます。
- 設定はすべてのシーンコレクションで共通です。

## 6. 表示位置・大きさ・切り替え効果の変え方

- **位置**: プレビュー上で「Clipboard Image」を動かすと、それ以降に表示する画像もその位置に表示されます。
- **大きさ**: 最大サイズを超える画像だけ縮小します(縦横比は保ちます)。小さい画像は元の大きさで表示します。ドラッグで大きさを変えた場合は表示中の画像だけが変わり、次の画像は最大サイズの設定で大きさが決まります。
- **境界設定**: 自動縮小は、境界設定が「自動」のときのみ有効です(右クリック →「変換」→「変換の編集」)。大きさを自分で決めたい場合は、境界設定を「内側に合わせる」などに変更するとその枠で大きさが決まります。
- **切り替え効果**: 右クリック →「表示トランジション」「非表示トランジション」で変更できます。変更した内容はそのまま使用されます。
- 「Clipboard Image」に設定したフィルタなど、ソースの設定はそのまま使用されます。

## 7. 保存される画像

画像の取り扱いについては[プライバシーポリシー](../../README.ja.md#プライバシーポリシー)をご覧ください。

表示した画像は次のフォルダに保存されます。

`%APPDATA%\obs-studio\plugin_config\clipboard-image-overlay\images`

新しい順に 50 枚まで残り、古い画像は自動で削除されます。表示中の画像は削除されません。

## 8. 困ったとき

### 画像が表示されない

- 画像がコピーされているか確認してください。テキストやリンクだけをコピーした場合は表示されません。
- WebP などの画像ファイルは OBS で対応していないため、アニメーションは静止画として表示されます。
- それでも表示されない場合は、ログを添えて[不具合・ご要望](#9-不具合ご要望)からお知らせください。

### ログの見方

「ヘルプ」→「ログファイル」→「現在のログファイルをアップロード」で URL を取得できます。不具合を報告するときはこの URL を添えてください。このプラグインのログは `[clipboard-image-overlay]` で始まります。

### 既知の制限

- **他のプラグイン・Stream Deck・obs-websocket で表示した場合**: 手動で表示したときと同じく表示時間が経過すると非表示になります。表示し続けたい場合は表示時間を 0 秒にしてください。
- **グループに入れた場合**: 「Clipboard Image」はグループに入れずに使うことを推奨します。グループに追加しても動作しますが、手動で表示状態にしたときは自動で非表示になりません。また「常に最前面に表示する」はグループの中での最前面になります。必要に応じて設定をオフにしてください。

## 9. 不具合・ご要望

「ツール」→「Clipboard Image」→「設定...」の画面の下にある「不具合・ご要望」のリンクからお知らせください。使っている環境が自動で入力されます。設定画面を開けない場合は、[不具合・ご要望フォーム](https://docs.google.com/forms/d/e/1FAIpQLSeOoU9HNzkLZx70GtSAoAbp-y8T491vJsohMwMT1NJjwKI_xA/viewform?usp=pp_url&entry.11414643=Clipboard+Image+Overlay)からお知らせください。
