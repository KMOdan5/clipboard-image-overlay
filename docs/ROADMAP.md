# MVP Issue 一覧

上から順に、1 Issue = 1 PR で進める。各 Issue の「完了条件」を Windows の OBS で確認できたらマージ。

## #2 テンプレートのビルドを通す
- buildspec.json のプラグイン名・作者情報を設定する
- GitHub Actions で Windows / macOS / Linux のビルドが成功する
- **完了条件:** Windows 版成果物を OBS に入れて起動すると、ログに `[obs-clipboard-image] plugin loaded successfully` が出る

## #3 メニュー項目とホットキーを登録する
- CMake で `ENABLE_FRONTEND_API` / `ENABLE_QT` を ON にし、ソースを C++ 化する
- 「ツール」メニューに「クリップボードの画像を表示」(Show Clipboard Image)を追加
- OBS のホットキー設定に同名のホットキーを登録(割り当てはシーンコレクションに保存)
- **完了条件:** メニュー／ホットキー操作でログが出る

## #4 クリップボードから画像を取得して保存する
- `QClipboard` から画像データ、またはコピーされた画像ファイルのパスを取得
- プラグイン専用フォルダ(`plugin_config/obs-clipboard-image/images`)に保存(ファイル名は日時ベース)
  - コピーしたファイルは元の形式のまま保存(GIF のアニメーションを維持)。OBS で表示できない形式と回転情報付きの写真だけ PNG に変換
  - 画像データ(スクショ・ブラウザの「画像をコピー」)は PNG で保存
- 画像がないときはログを出して何もしない
- **完了条件:** ブラウザで「画像をコピー」/ `Win+Shift+S` / エクスプローラーでファイルをコピー の3パターンで画像が保存され、アニメーション GIF は動いたまま保存される

## #5 画像ソースとして現在のシーンに追加・配置する
- 専用の画像ソース(名前固定: `Clipboard Image`)を作成または再利用し、保存した画像を設定
- シーンに初めて追加したときだけ、画面中央に配置。境界は OBS の既定と同じ「自動」
- 貼るたびに画像の大きさを見て、画面の幅・高さの 60% を超える画像だけ縮小(表示サイズ=「大きさ」の幅・高さを調整。縦横比維持、小さい画像は等倍)。60% は #8 で設定可能にする
- 配信者が後から動かした位置は上書きしない。画像や画面の大きさが取れないときは等倍で表示
- 表示サイズの調整は境界が「自動」のときだけ行う(自動以外は境界の枠に任せる)
- 最前面に移して表示状態にする
- **完了条件:** ホットキーで現在のシーンに画像が表示される

## #6 フェードイン → N秒 → フェードアウト
- シーンアイテムの表示/非表示トランジションにフェード(0.4 秒)を設定。未設定のときだけ設定し、配信者の設定は上書きしない
- 初めて追加するときも非表示で追加してからフェードインさせる
- タイマーで 7 秒後に非表示にする。表示中に再度ホットキーで延長(タイマーを最初からやり直す)
- 消すときは全シーンの Clipboard Image を非表示にする(シーンを切り替えても出しっぱなしにしない)
- OBS 終了時はタイマーを止める
- 表示秒数とフェード時間は #8 で設定可能にする
- **完了条件:** 画像が自動で消える。消し忘れが起きない

## #7 固定表示モードと差し替え
- 固定表示用ホットキー(自動で消えない)と、手動で消すホットキー
- 表示中に新しい画像を貼ると、前の画像と差し替わる
- **完了条件:** 2つのモードが切り替えられ、連続で貼っても画像が重ならない

## #8 設定画面
- 表示秒数・位置・最大サイズ(画面に対する割合、既定 60%)・フェード時間を設定できるダイアログ
- 表示サイズの自動調整のオン/オフ(「境界が『自動』のときだけ有効」と画面に明記する)
- 設定は OBS の設定ファイルに保存
- **完了条件:** OBS を再起動しても設定が残る

## #9 一時ファイルの掃除
- 保存フォルダの画像を、件数または日数の上限で自動削除
- **完了条件:** 上限を超えた古い画像が OBS 起動時に削除される
