# MVP Issue 一覧

上から順に、1 Issue = 1 PR で進める。各 Issue の「完了条件」を Windows の OBS で確認できたらマージ。

## #2 テンプレートのビルドを通す
- buildspec.json のプラグイン名・作者情報を設定する
- GitHub Actions で Windows / macOS / Linux のビルドが成功する
- **完了条件:** Windows 版成果物を OBS に入れて起動すると、ログに `[obs-clipboard-image] plugin loaded successfully` が出る

## #3 メニュー項目とホットキーを登録する
- CMake で `ENABLE_FRONTEND_API` / `ENABLE_QT` を ON にし、ソースを C++ 化する
- 「ツール」メニューに「クリップボードの画像を表示」(Show Clipboard Image)を追加
- OBS のホットキー設定に同名のホットキーを登録(割り当てはシーンコレクションに保存)
- **完了条件:** メニュー／ホットキー操作でログが出る

## #4 クリップボードから画像を取得して保存する
- `QClipboard` から画像データ、またはコピーされた画像ファイルのパスを取得
- プラグイン専用フォルダ(`plugin_config/obs-clipboard-image/images`)に保存(ファイル名は日時ベース)
  - コピーしたファイルは元の形式のまま保存(GIF のアニメーションを維持)。OBS で表示できない形式と回転情報付きの写真だけ PNG に変換
  - 画像データ(スクショ・ブラウザの「画像をコピー」)は PNG で保存
- 画像がないときはログを出して何もしない
- **完了条件:** ブラウザで「画像をコピー」/ `Win+Shift+S` / エクスプローラーでファイルをコピー の3パターンで画像が保存され、アニメーション GIF は動いたまま保存される

## #5 画像ソースとして現在のシーンに追加・配置する
- 専用の画像ソース(名前固定: `Clipboard Image`)を作成または再利用し、保存した画像を設定
- シーンに初めて追加したときだけ、画面中央に配置。境界は OBS の既定と同じ「自動」
- 貼るたびに画像の大きさを見て、画面の幅・高さの 60% を超える画像だけ縮小(表示サイズ=「大きさ」の幅・高さを調整。縦横比維持、小さい画像は等倍)。60% は #8 で設定可能にする
- 配信者が後から動かした位置は上書きしない。画像や画面の大きさが取れないときは等倍で表示
- 表示サイズの調整は境界が「自動」のときだけ行う(自動以外は境界の枠に任せる)
- 貼るたびに最前面に移す(「常に手前に表示する」既定オン。#8 でオフにできるようにする)。表示状態にする
- **完了条件:** ホットキーで現在のシーンに画像が表示される

## #6 フェードイン → N秒 → フェードアウト
- シーンアイテムの表示/非表示トランジションにフェード(0.4 秒)を設定。設定するのはシーンに初めて追加したときだけ。以降は「なし」を含め配信者の設定を変えない
- 初回以降にプラグインが変えるのは、画像ファイル・表示サイズ(境界が自動のとき)・重なり順(常に手前がオンのとき)・表示/非表示だけ
- 初めて追加するときも非表示で追加してからフェードインさせる
- タイマーで 7 秒後に非表示にする。表示中に再度ホットキーで延長(タイマーを最初からやり直す)
- 表示中に新しい画像を貼ったときは、フェードアウト → 差し替え → フェードイン(方式 A。ソースは 1 つのまま)
- 消すときは全シーンの Clipboard Image を非表示にする(シーンを切り替えても出しっぱなしにしない)
- OBS 終了時はタイマーを止める。表示中に終了すると表示状態のまま保存されるため、起動完了時・シーンコレクション切り替え時にフェードなしで即座に非表示にする
- 表示時間は #8 で設定可能にする(フェードの長さは OBS 標準のトランジション設定で変える)
- **完了条件:** 画像が自動で消える。消し忘れが起きない

## #7 自動で消えるタイマーの一時停止ホットキー
- ホットキーで自動で消すタイマーを一時停止/再開する(表示中だけ有効。再開は残り時間から)
- 貼ると残り時間は 7 秒に戻る。一時停止中に貼ったら一時停止のまま
- 画像が非表示になったら(手動でも自動でも)一時停止を解除する。非表示は OBS の item_visible 通知で検知する
- 手動(目のアイコン・OBS 標準のホットキー)で表示したとき・表示状態でシーンに追加したときも、貼ったときと同じく 7 秒のカウントを始める
- シーンからの削除(ソースの削除を含む)は非表示と同じ扱い。「表示中」は全シーンで判断し、どのシーンにも表示されなくなったら一時停止を解除する
- 全シーンの item_visible / item_add / item_remove 通知で検知する。プラグイン自身の操作は二重に数えない。シーンコレクションの切り替え・終了より前の古い通知は処理しない。差し替え待ちの間にアイテムやシーンが削除されたら差し替えを取り消す
- 手動で消すのは OBS 標準(目のアイコン、各シーンの「'Clipboard Image' を非表示」ホットキー)。専用の固定表示ホットキーは作らない(出しっぱなしは #8 の表示時間 0 秒)
- **完了条件:** Issue #7 の状態表のとおりに動く。手動で消したあとに貼っても、手動で表示し直しても、普段どおり 7 秒で消える

## #8 設定画面
- 表示時間(既定 7 秒。0 秒なら自動で消さず、手動で消すまで表示し続ける)・最大サイズ(画面に対する割合、既定 60%)を設定できるダイアログ
  - フェードの長さはプラグインの設定に含めない(OBS 標準の表示/非表示トランジションで変更できる)
- 表示サイズの自動調整のオン/オフ(「境界が『自動』のときだけ有効」と画面に明記する)
- 「常に手前に表示する」のオン/オフ(既定オン。オンなら貼るたびに最前面へ移す)
- 「ツール」メニューの「Clipboard Image の設定...」から開く
- 設定はプラグインの設定フォルダの `settings.json` に保存(シーンコレクション共通)
- 変更は次に画像を表示したときから反映(表示中のタイマー・大きさは変えない)
- **完了条件:** OBS を再起動しても設定が残る

## #9 一時ファイルの掃除
- 保存フォルダの画像を、件数または日数の上限で自動削除
- **完了条件:** 上限を超えた古い画像が OBS 起動時に削除される
