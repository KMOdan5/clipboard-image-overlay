# ユースケース

Clipboard Image Overlay が、どんな配信のどんな場面で使われているか(使いたいと言われているか)をまとめます。ヒアリングや配信で見た使われ方をもとにしています。新しい使われ方が分かったら、ここに足していきます。

| 場面 | 今できること | 関連 |
|---|---|---|
| 雑談配信で、見つけた画像をすぐに見せる | コピーしてホットキーで表示し、数秒で自動で非表示になる | — |
| ゲーム配信で、ゲームの画面を切り取って見せる | `Win + Shift + S` で切り取ってそのまま表示する | — |
| さっき見せた画像を、もう一度見せる | 表示履歴のドックや「前の画像を表示」で出し直す | — |
| スタジオモードで配信している | 「スタジオモードでもすぐに配信画面に表示する」をオンにする | #131 |
| 小さい画像を、毎回同じ大きさで見せる | 境界の種類を「内側に合わせる」にする | — |
| 雑談で、2〜3 枚の画像を比べて見せたい | まだできない(1 枚ずつ) | #80 |
| 記念配信やレポート配信で、もらったイラストや写真を 1 枚ずつ紹介し、最後にまとめて並べたい | 1 枚ずつは出せる。前もって準備したり、まとめて並べたりはまだできない | #80・#162 |
| 縦型配信など、別のキャンバスでも見せたい | まだできない | #19 |
