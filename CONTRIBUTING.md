# 参加のしかた / Contributing

このプラグインに興味を持っていただき、ありがとうございます。

Thank you for your interest in this plugin.

## 不具合・要望 / Bugs and ideas

不具合の報告や要望は、[不具合・ご要望フォーム](https://docs.google.com/forms/d/e/1FAIpQLSeOoU9HNzkLZx70GtSAoAbp-y8T491vJsohMwMT1NJjwKI_xA/viewform?usp=pp_url&entry.11414643=Clipboard+Image+Overlay)から送ってください。GitHub の [Issue](https://github.com/KMOdan5/clipboard-image-overlay/issues/new/choose) からも送れます。日本語・英語のどちらでも構いません。

Please send bug reports and requests via the [form](https://docs.google.com/forms/d/e/1FAIpQLSeOoU9HNzkLZx70GtSAoAbp-y8T491vJsohMwMT1NJjwKI_xA/viewform?usp=pp_url&entry.11414643=Clipboard+Image+Overlay) (in Japanese) or [Issues](https://github.com/KMOdan5/clipboard-image-overlay/issues/new/choose). Japanese or English is fine.

## プルリクエスト / Pull requests

現在は、外部からのコードのプルリクエストは受け付けていません。
改善の提案は、まず Issue で相談してください。

We are not accepting code pull requests from outside contributors at the moment.
Please open an issue to discuss your idea first.

## セキュリティ / Security

脆弱性は公開の Issue ではなく、[SECURITY.md](SECURITY.md) の方法で非公開で報告してください。

Please report security issues privately as described in [SECURITY.md](SECURITY.md).
